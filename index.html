Interactive UI with zero JavaScript.

Six components built from native HTML and modern CSS. One stylesheet, no build step, nothing to hydrate. Everything on this page works, and this page loads 0 script tags.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/YOUR_USERNAME/nojs-ui@main/css/nojs-ui.css">

Modal

A <dialog> with the popover attribute. Esc and clicking outside both close it. Focus returns to the button.

<button class="nj-btn" popovertarget="demo-modal">Delete project</button>

<dialog id="demo-modal" class="nj-modal" popover>
  <h3>Delete this project?</h3>
  <p>All files and history will be removed.</p>
  <div class="nj-actions">
    <button class="nj-btn" popovertarget="demo-modal"
            popovertargetaction="hide">Keep project</button>
  </div>
</dialog>

Drawer

A side panel that slides in from the right. Same popover mechanism, different shape.

<button class="nj-btn" popovertarget="demo-drawer">Filter results</button>

<div id="demo-drawer" class="nj-drawer" popover>
  <h3>Filters</h3>
  <label><input type="checkbox"> In stock</label>
  <div class="nj-actions">
    <button class="nj-btn nj-btn--primary" popovertarget="demo-drawer"
            popovertargetaction="hide">Show results</button>
  </div>
</div>

Dropdown menu

A popover pinned to its button with CSS anchor positioning. It flips upward when there is no room below. Give the button and the menu the same anchor name.

<button class="nj-btn" popovertarget="actions"
        style="anchor-name: --actions">Project actions</button>

<div id="actions" class="nj-menu" popover
     style="position-anchor: --actions">
  <button type="button">Rename</button>
  <button type="button">Duplicate</button>
  <button type="button">Archive</button>
</div>

Tooltip

Add data-tip to any element. It shows on hover and on keyboard focus. Also set aria-label when the tip names an icon-only button, since screen readers do not read generated text.

<button class="nj-btn" data-tip="Saved 2 minutes ago">Save</button>

Tabs

Radio buttons plus :has(). Arrow keys switch tabs natively and no ids are needed. Each panel sits right after its label.

Accordion

Plain <details> elements that share a name, so opening one closes the others. The height animation is a bonus in newer browsers.

Do I need a build step?

No. Link one CSS file and write HTML.

Can I change the colors?

Yes. Override the --nj-* custom properties, such as --nj-accent.

Does it support dark mode?

Yes. It follows the system setting through light-dark().

<div class="nj-accordion">
  <details name="faq" open>
    <summary>Do I need a build step?</summary>
    <p>No. Link one CSS file and write HTML.</p>
  </details>
  <details name="faq">...</details>
</div>
